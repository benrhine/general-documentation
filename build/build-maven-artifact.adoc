= Maven: Build Artifact
:toc:

The https://maven.apache.org[Apache Maven build system] is still extremely common but is considered a legacy build system for Java
applications. While maven is still a great tool, it is
somewhat confusing in how to do more advanced configuration since it is based on XML and is lacking much of the flexibility
that is available through the groovy scripting available through Gradle (Gradle also supports Kotlin).

== Maven Wrapper

It is recommended to always use the Maven Wrapper artifact (./mvnw) so that it can be included directly in the
repository alongside the code to ensure that anyone who checks out the code is immediately able to execute the code and
to guarantee that developers are all using the same version of Maven when operating on the code. The easiest way to get
the wrapper is copy it from an existing project or download it with a template project from the
https://start.spring.io[Spring Initializr]. Once you have the wrapper artifact, it can be upgraded by executing the
following command and supplying the version you wish to upgrade or downgrade to.

[NOTE]
You must have maven natively installed on the local system in order to perform the wrapper upgrade

[source, shell]
----
mvn wrapper:wrapper -Dmaven=3.5.4
----

== Check Version

To check what version of Maven is being used

[source, shell]
----
./mvnw -v
----
