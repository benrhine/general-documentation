= Properties

This page and any sub-pages are dedicated to tracking properties that are used within all* environments. While some
properties may be under version control and included in the deployment pocess others are not or can not be put in the
repositories for security reasons.

[NOTE]
System Manager Properties (Including SecureStrings) are free (or at least quite a few are)

[CAUTION]
SecureString properties will not work with CloudFormation
