This page is intended to be the top level container for reference documentation. What do we mean when we say "Reference Documentation"? Reference documentation is any documentation that is important to know how something is/was done but is not actively used in day to day development processes.

== When is this useful?

* Historical notes of what was or was not done
* In the event of a catastrophic disaster and we need a overview of how things were configured
* More deeply understanding the architecture from beginning to end

== When is this not useful?

* This is not generally useful day to day as once these items are in place they will rarely, if ever need updated.
* Will not help you understand day to day work
