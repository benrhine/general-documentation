AWS Systems Manager (SSM) parameters, particularly those within Parameter Store, are regional by default, not global.

== This means:
=== Scope:
Parameters created in one AWS Region are only accessible within that specific Region.

=== Isolation:
A parameter with the same name can exist in different Regions, and these are distinct entities.

=== Management:
You manage and access parameters within the context of the Region where they are created.

While AWS does offer some "global services" like IAM or Route 53, and certain operations within regional services might have global dependencies, SSM Parameter Store itself operates on a regional basis.
If you require access to the same parameter values across multiple Regions, you would typically need to replicate those parameters in each desired Region or implement a mechanism to fetch them from a central location.
