[TIP]
This team follows the "Docs as Code" philosophy.

== Why practice the "Docs as Code" philosophy?

* Documentation lives with the code so it is never lost
* Documentation is versioned the same as code so documentation changes are never lost
* Writing documentation alongside the code incentivises good dev behavior
* It makes documentation easier
* It makes documentation a first class citizen of the dev process
* Hopefully means documentation is regularly updated and not forgotten about.
* Streamlines process by making updates occur when code is built
