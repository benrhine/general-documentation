== CD: CodePipeline

Continuous Deployment (CD) using Aws CodePipeline is where everything comes together to take newly developed code,
link:../engineering/development/testing/testing-unit.adoc[unit]
and link:../engineering/development/testing/testing-integration.adoc[integration testing], link:build-ci-codebuild.adoc[build], deploy, and
link:../engineering/development/testing/testing-api-smoke.adoc[verify] using automation.

== Pipeline

It is expected that a pipeline will be constructed using the individual pieces configured under
link:build-ci-codebuild.adoc[CI: CodeBuild]. CodeBuild
represents the individual steps necessary to consider building a fully automated deployment, the pipeline (CD) is the
realization of that automation.

== Configuring a CodePipeline

To setup CD using a pipeline see link:../../../engineering/cloud/infrastructure/aws/aws-setup-code-pipeline.adoc[Setup: AWS CodePipeline]
