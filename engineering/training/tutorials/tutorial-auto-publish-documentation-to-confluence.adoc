This tutorial combines several How To's into a single tutorial to fully describe how to automatically publish documentation to Confluence.

== Why would you want to auto publish your documentation?

The reasons for this are many but to provide a few ...

* Documentation lives with the code so it is never lost
* Documentation is versioned the same as code so documentation is never lost
* Writing documentation alongside the code incentivizes good dev behavior
* It makes documentation easier
* It makes documentation a first class citizen of the dev process
* Hopefully means documentation is regularly updated and not forgotten about.

== How to do it

Start by adding and configuring `asciidoc` to the project.

* {tl-how-to-link-052}[How To - Asciidoc]

Next, make sure you have a Personal Access Token configured for Confluence

* {tl-how-to-link-056}[How To - Configure Confluence Personal Access Token]

Now, once you are happy with how the documentation is being generated by Asciidoc and a personal access token has been configured, add in the `publishToConfluence` plugin.

* {tl-how-to-link-069}[How To - Publish to Confluence]
