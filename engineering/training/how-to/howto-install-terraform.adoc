To install Terraform start by navigating to the https://developer.hashicorp.com/terraform/install?product_intent=terraform[Terraform Download] page.

=== MacOS

[source, bash]
----
brew tap hashicorp/tap
brew install hashicorp/tap/terraform
----

=== Windows

Download the executable files and follow the installer.

=== Linux

See the Linux section of the top link for distro specific instructions.

== Reference

There is also a brew install available directly from the brew website but it only installs an old version of terraform.
It is highly suggested to NOT INSTALL from this script and to use the official install provided via HashiCorp.

* https://formulae.brew.sh/formula/terraform
