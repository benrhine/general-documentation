[WARNING]
This will ONLY work for lambdas using the REST API, NOT the HTTP API!!!

== buildspec.yml

In the `buildspec.yml` add `npm install serverless-whitelisting`  (for correct ordering not the snippet below)

[source, yaml]
----
- npm install -g serverless
- echo "Installing Serverless plugins"
- npm install serverless-whitelisting
----

== serverless.yml

In the plugin sections add

[source, yaml]
----
plugins: # Specify any additional plugins for serverless - be aware that these can increase cold start time
    - serverless-whitelisting
----

== Configure the plugin


[source, yaml]
----
custom:
  serverless-whitelisting:
    stage: ${self:provider.stage}
    privateStages:
      - dev
      - test
      - rgrs
      - uat
      - stage
    publicStages:
      - prod
    netblocks:
      - 127.0.0.1
    publicPaths:
      - /my-path
----
