== Quick and Dirty version

* Add the git-changelog-gradle-plugin
** https://plugins.gradle.org/plugin/se.bjurr.gitchangelog.git-changelog-gradle-plugin
* Configure the plugin
* Add a step to the GitHub Documentation Publishing Workflow
* Allow documentation publishing to occur as normal
** This will pick up the newly generated changelog file
