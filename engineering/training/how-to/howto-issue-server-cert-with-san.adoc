== Prerequisites
You must have an existing Private Certificate Authority created in AWS. If you do not have one, please refer to the {tl-how-to-link-060}[How To - Create a Private Certificate Authority in AWS] guide.
You also will need openssl installed on your local machine to generate a Certificate Signing Request (CSR).

== Steps to Issue and Sign Server Certificates with SAN
1. **Create a config file with SAN:**
    - Create a configuration file (e.g., `server.conf`) that includes the Subject Alternative Names (SAN) you want to include in the certificate.
+
[source, bash]
----
cat > server.conf <<EOF
[req]
distinguished_name = req_distinguished_name
req_extensions = v3_req
prompt = no

[req_distinguished_name]
C = US
ST = California
L = San Francisco
O = YourCompany
OU = IT
CN = <YOUR_DOMAIN>.com

[v3_req]
keyUsage = critical, digitalSignature, keyEncipherment
extendedKeyUsage = serverAuth
subjectAltName = @alt_names

[alt_names]
DNS.1 = <YOUR_DOMAIN>.com
EOF
----

2. **Generate a Certificate Signing Request (CSR) and Key:**
    - Use OpenSSL to generate a private key and CSR using the configuration file created in the previous step.
+
[source, bash]
----
# Generate new server key and CSR
openssl genrsa -out server.key 2048

openssl req -new -key server.key -out server.csr -config server.conf
----

3. **Sign the CSR with AWS Private CA:**
    - Use the AWS CLI to issue a certificate using the CSR generated in the previous step.
+
[source, bash]
----
# Issue server certificate from AWS Private CA
SERVER_CERT_PCA_ARN=$(aws acm-pca issue-certificate \
  --certificate-authority-arn $CA_ARN \
  --csr fileb://server.csr \
  --signing-algorithm "SHA256WITHRSA" \
  --template-arn arn:aws:acm-pca:::template/EndEntityCertificate/V1 \
  --validity Value=7,Type="DAYS" \
  --region us-west-2 \
  --profile brr \
  --query 'CertificateArn' \
  --output text)

# Wait for the certificate to be issued
# Retrieve the server certificate
aws acm-pca get-certificate \
  --certificate-authority-arn $CA_ARN \
  --certificate-arn $SERVER_CERT_PCA_ARN \
  --region us-west-2 \
  --profile brr \
  --query 'Certificate' \
  --output text > server.crt
----
+
[NOTE]
For the `CA_ARN`, you can find it in your AWS Private CA using the AWS CLI or AWS Management Console. See the {how-to-11-link}[How To - Create a Private Certificate Authority in AWS] guide for more details.

4. **Verify the Issued Certificate:**
    - You can verify the issued certificate using OpenSSL:
+
[source, bash]
----
openssl x509 -in server.crt -text -noout
----
    - This command will display the details of the issued certificate, including the issuer, subject, SANs, and validity period.
