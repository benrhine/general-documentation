# general-documentation

This repository contains my distilled notes over a dozen different roles from start ups to Fortune 500 companies.
The goal is to be able to shorten the amount of time it takes me to stand up new implementations or more quickly respond
to a given issue at a company. 

This documentation has also been sanitized of any company information so that it can be portable between roles and allow
me to more quickly bring necessary documentation and notes to any new team in the future.
