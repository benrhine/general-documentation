== CloudFormation
:toc:

CloudFormation is a proprietary IaC language that only works with AWS. It can be leveraged in the following ways ...

* Create a template in either JSON or YAML and uploaded through the Aws Console.
* Create a template and upload/deploy through the Aws CLI (pretty sure this is the case but not 100% - I have not done this)
* Might be able to be leveraged through link:../../cloud/infrastructure/aws/aws-sam.adoc[SAM] or
link:../../cloud/infrastructure/aws/aws-cdk.adoc[CDK] - Unknown; I have not explored either of these options
