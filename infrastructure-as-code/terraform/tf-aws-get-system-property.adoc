= Terraform: (AWS) Get system property

[NOTE]
To view details on System Manager Parameters/Properties, see link:../../cloud/infrastructure/aws/aws-system-parameters.adoc[System Parameters]



== Retrieve system property

.To retrieve SSM within data.tf
[source, shell]
----
data "aws_ssm_parameter" "my_parameter" {
  name = "/my/path/to/my_parameter"
}
----

.Use retrieved property in variables.tf
[source, shell]
----
variable "environment_tag" {
  description = "Name of environment"
  type        = string
  default     = data.aws_ssm_parameter.my_parameter.value
}
----
